                  支持范围与限制

                  当前范围：ChatGPT 个人空间普通对话及豆包网页普通对话。豆包按消息链完整分页；非正文块和重新生成记录保留在 JSON。豆包原图支持 byteimg.com 来源，其他尚未适配资源保留原始信息并提示待处理。支持图片、ZIP、GZIP / TAR.GZ、PDF、DOCX / XLSX / PPTX 与常见文本附件，单文件上限 32 MiB（gzip 校验后的内容也限 32 MiB）。无法取得的附件标记待处理；内部看图附件返回 404 后单独标记未下载。

                  设置

                  本地备份

                  对话默认保存 JSON 和 Markdown。关闭附件自动下载后，新附件按设置暂停，已保存文件保留；需要时可手动补齐。浏览器运行且账号可访问时执行。

                  保存位置

                  迁移前先复制整个归档目录，再选择副本；选择空目录不会自动搬迁旧文件。切换后先“检查更新”，有缺失时再到高级操作“补齐缺失”。

                  GitHub 备份（可选）

                  高级设置

                  自动恢复与自动上传独立，可用于多台电脑补齐备份。

                  凭据仅保存在此浏览器。自动上传关闭时仍可手动备份对话。图片和附件保存在本地，GitHub 中的 Markdown 图片可能无法显示；迁移电脑时请一并复制本地附件目录。

                  从 GitHub 恢复对话

                  下载已保存仓库中各账号的对话到所选目录，无需登录来源平台。请先保存仓库配置并授权本地目录；附件需从原电脑复制或绑定来源账号后补采；恢复不会启用账号采集。

                  平台访问

                  按需授权平台，再到对应网页打开采集器并启用当前账号。

                  外链附件

                  可选：授权后，扩展会匿名检测对话中的 HTTPS 外链图片及受支持文件。此权限覆盖 HTTPS 网站；请求不携带 AI 平台或 GitHub 凭据。未授权的外链保留原始链接。

                  诊断与日志

                  查看当前账号与仓库恢复的近期步骤、失败原因和已恢复记录。日志保存在本浏览器，可导出脱敏诊断。

                  当前账号

                  账号按实际登录身份识别。切换身份后先核验；新账号需要单独启用。

                  隐藏后，点击浏览器工具栏的采集器图标即可恢复。

                    脱敏导出预览

                    导出所选账号与仓库恢复的保留记录，不受列表筛选影响。只含版本、平台、时间、阶段、固定错误码和计数；对象使用本次导出内的匿名编号。不包含正文、标题、文件名、账号名称、凭据、网址或完整本地路径。
