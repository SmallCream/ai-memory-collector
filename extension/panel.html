    自动采集

    浏览器运行且账号可访问时执行。定时任务与手动任务共用进度，不重复启动。

    默认生成 JSON 与 Markdown；更换目录后可用“全量补采”补齐文件。

    GitHub 同步

    凭据仅保存在此浏览器。启用后上传本地归档，并定时恢复仓库中各账号的归档与图片；保留本地手工改动，不因远端缺失删除文件。图片使用 GitHub LFS 的存储与流量额度；关闭图片同步仍保留本地图片。

    从 GitHub 恢复 / 补齐图片

    下载已保存仓库中各账号的对话与图片到所选目录，无需登录 ChatGPT。请先保存仓库配置并授权本地目录；恢复不会启用账号采集。

    外链图片

    可选：授权后，扩展会匿名检测对话中的 HTTPS 外链图片。此权限覆盖 HTTPS 网站；请求不携带 ChatGPT 或 GitHub 凭据。未授权的外链保留原始链接。

    当前账号

    账号按实际登录身份识别。切换身份后先核验；新账号需要单独启用。
