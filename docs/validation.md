版本：0.1.5。记录日期：2026-10-21。

0.1.0 基线：Node.js 24.19.0 下 50 项测试通过。0.1.1 新增实际面板事件处理回归测试，覆盖授权等待、就地错误、控件恢复、输入校验、远端成功但本机设置保存失败、启动锁定及错误中的凭据遮蔽；另覆盖独立启动脚本的加载失败和超时反馈。未执行真实账号和用户设备端到端测试。

0.1.1 结果：59 项自动化测试全部通过，静态检查及扩展打包通过。已修复可复现的反馈缺陷；用户实际连接是否仍有网络或权限错误，需要更新后查看就地错误提示，不能据此标记真实 GitHub 接入已通过。

0.1.2 修复：GitHub 客户端把原生 `fetch` 存入配置后以配置对象作为接收者调用，违反浏览器的接收者检查；异常被统一映射为 `NETWORK`。现在显式使用 `globalThis` 作为接收者。新增回归测试模拟浏览器的接收者约束，覆盖默认客户端的仓库读取、合成文件写入和读回；修改前失败并复现 `NETWORK`，修改后通过。该测试不连接真实 GitHub，也不使用用户 Token。

0.1.2 结果：60 项自动化测试全部通过，静态检查通过，打包内容与扩展源文件逐字节一致。未在用户浏览器完成真实 GitHub 连接与提交验收。

0.1.3 调整：Markdown 改为对话阅读版，移除采集元数据、消息 ID 和哈希标题，普通正文直接使用 Markdown，系统与工具等明确的内部消息只保留在 JSON 中。采集完整度、分支选择、原生 JSON 与写入保护仍独立保留；新排版不代表采集完整度已经验证。

0.1.3 结果：63 项自动化测试全部通过，静态检查通过，安装包与扩展源码逐字节一致。覆盖正文排版、表格和代码保留、内部消息筛选、附件占位、HTML 转义及未闭合代码块的消息边界。已用虚构对话生成 `docs/markdown-example.md` 供阅读核对；真实对话的新阅读版仍需用户更新后验证。

0.1.4 调整：复用已有采集标签页并防连续点击重复创建；普通表单设置自动保存，Token 仅显式勾选后在本机持久保存，可取消或清除。设置写入串行化，旧保存不会在清除后重新写回 Token；采集摘要与接口选项默认折叠。沿用既有数据库与扩展身份，不把账号验证和个人空间确认当作可恢复的偏好。

0.1.4 结果：74 项自动化测试全部通过，静态检查通过，安装包内 10 个扩展文件与源码逐字节一致。新增覆盖标签页复用、连续点击、关闭后恢复、设置重开恢复、连接失败后的设置保留、Token 选择保存与清除竞态、旧设置迁移和本机写入失败反馈。未在用户设备执行真实浏览器更新、目录授权与 Token 恢复验收。

## 接口与实现参考

以下参考仅说明实现依据，不证明目标账号已经可用：

- [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)：将自包含函数注入受授权页面的隔离环境。
- [Chrome File System Access](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)：用户手势选择真实目录、保存句柄、核验权限和写入。
- [GitHub Contents API](https://docs.github.com/en/rest/repos/contents)：私有仓库合成文件创建与读回。
- [GitHub References API](https://docs.github.com/en/rest/git/refs)：查询分支指向。
- [ChatGPT-Exporter 接口说明](https://github.com/Kirito-Elucidator/ChatGPT-Exporter/blob/main/README.md)：公开项目记录的会话、列表和旧版详情路径，仅用于定位实验接口，未复制其实现代码。
- [chatgpt-conversation-export 格式说明](https://github.com/ThierryAbalea/chatgpt-conversation-export/blob/main/docs/format.md)：公开项目记录的 messages/page_info 与 mapping 结构差异，仅作为实验适配依据。

上述网站内部接口不是官方稳定 API 契约，可能随账号和日期变化。本项目不绕过登录、额外挑战或访问限制。
