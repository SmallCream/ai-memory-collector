# 开发路线图与验收

当前为文档初始化阶段。以下阶段均未完成；任务勾选必须有对应实现和验证记录。

## P0：接入原型

目标：验证纯浏览器扩展的核心前提，明确哪些能力能承诺。

- [ ] 建立最小扩展，记录目标 Chrome / Edge 版本与必要权限。
- [ ] 读取并核验稳定账号身份，区分显示名称、工作区与当前会话。
- [ ] 验证会话列表分页、更新时间语义与普通/项目/归档等范围。
- [ ] 获取普通、长对话、编辑/重新生成/分支样例，解释实际覆盖。
- [ ] 比较网页响应与官方导出结构，记录格式名与兼容边界。
- [ ] 用户选择真实目录，验证读写、重启和后台恢复后的权限行为。
- [ ] 对用户明确指定的测试数据仓库完成一次 GitHub API 提交并读回。
- [ ] 记录失败、限制和可复现结果，不保存真实正文、凭据或未脱敏抓包。

通过条件：账号可靠可区分，采集范围可解释，真实文件能落盘，GitHub 提交可核对。未通过的能力保持限制，不自行引入本地服务。测试优先使用人工创建的无敏感内容对话及专用测试仓库。

## P1：单账号归档

- [ ] 原生 JSON 与对应格式、覆盖说明。
- [ ] 从确定 JSON 版本生成 Markdown，保留消息锚点与分支说明。
- [ ] 固定路径与对话唯一键，完善标题和时间缺失处理。
- [ ] 共享归档清单、排除项与设备本地状态分离。
- [ ] 近期优先扫描、历史补抓与可靠入队后推进水位。
- [ ] 重复采集幂等，续聊和标题变化更新同一档案。

通过条件：无变化不产生提交；部分详情不覆盖完整档案；同一逻辑对话只有一组规范文件。

## P2：账号切换与恢复

- [ ] 第二账号绑定、独立开关与范围。
- [ ] 切换废止 run，发送和入队前核验身份，隔离迟到响应。
- [ ] 已核验暂存的旧账号数据继续保存上传；关闭同步时停止新任务。
- [ ] 持久队列、限流退避、容量控制、目录重新授权。
- [ ] 后台终止、浏览器重启、断网后按版本恢复文件组。

通过条件：A/B 往返不串账号，失败可恢复，不丢未上传原文，不误报全部完成。

## P3：多设备与远端竞争

- [ ] 第二台电脑下载快照，独立授权目录和账号。
- [ ] 维护共同基准，按身份归并首次生成的不同路径。
- [ ] JSON 三方比较与来源重新拉取，Markdown 统一重建。
- [ ] 以最新远端树生成提交，非强制更新分支，竞争后重新合并。
- [ ] 提交超时读回确认，最终版本落实本地和远端后推进基准。
- [ ] 保护人工改动，少数无法判定的冲突集中处理。

通过条件：没有强制覆盖；同 ID 并发首建不留两套主档；无法确定的版本不静默丢弃。

## P4：可安装版本

- [ ] 配置向导、账号与范围页、采集状态、立即同步和暂停。
- [ ] 区分已发现、已采集、已保存本地、已上传和待处理。
- [ ] 文档、虚构样例、构建与安装说明、升级与迁移说明。
- [ ] 明确支持的平台/浏览器版本和未覆盖能力。
- [ ] 完成验收矩阵，选择许可证并准备发布流程。

通过条件：用户无需 Git 或本地程序即可配置并完成一次完整归档。

## 验收矩阵

| 场景 | 必须满足 |
| --- | --- |
| 普通与长对话 | 原文、代码、源 ID 和实际分页覆盖可核对 |
| 重复与无变化扫描 | 不重复建档，不因采集时间产生提交 |
| 续聊与改标题 | 更新同一记录，默认不改路径 |
| 编辑、重新生成和分支 | 保留源关系，不串联互斥回复 |
| 手机新增或更新 | 可用账号和受支持范围内后续扫描能发现 |
| A/B 切换和迟到响应 | 旧 run 失效，可靠暂存数据归属不变 |
| JSON 已写、Markdown 未写 | 恢复后补齐，不丢 JSON，不误报完成 |
| 断网、后台退出、目录失权 | 有界暂存、检查点恢复、授权后继续 |
| 两设备同 ID 首建 | 标题或日期不同也归并到规范路径 |
| 同消息内容冲突 | 可靠源版本或重新拉取裁决，临时失败自动等待 |
| 提交竞争与超时 | 不强推，重新读取合并，可识别已经成功 |
| 部分详情、列表缺失与删除 | 不覆盖完整档案，不误删，来源删除默认保留 |
| 人工修改和排除 | 保护改动，不重新采集排除项，不越界写入 |
| 新设备与旧档迁移 | 从归档恢复状态，不把旧 Markdown 伪装成原生 JSON |

## 验证记录要求

每项能力记录环境版本、适配器版本、日期、测试范围、结果与限制。公开记录仅使用虚构或充分去标识的数据，不包含原始账号身份、对话正文或认证信息。

接口或浏览器行为变化后，将受影响能力标记为待复验，保留已归档数据。文档描述和阶段勾选不能替代实测证据。
