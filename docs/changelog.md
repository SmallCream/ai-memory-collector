# 更新日志

当前均为开发版本；稳定渠道发布情况需另行确认。完整测试与实机证据见 [验证记录](validation.md)。

- **0.4.16**：首页按对话备份、附件下载、保存位置及诊断操作重组；进度与主操作同区，队列和说明按需展开。修正运行中显示自动采集暂停的歧义，列表扫描改为发现数量；有附件失败时突出重试，正常检查不再显示警告，空的 0/0 检查结果不展示。
- **0.4.15**：首页增加常显附件状态卡，分开显示已保存、排队／处理中及失败；失败为 0 也明确显示，未知统计不冒充成功。失败原因、重试和日志移至卡片内；下载详情折叠且仍有其他传输时保留失败数量。
- **0.4.14**：修复首次豆包备份勾选附件下载却未请求图片域名权限；拒绝授权时保留引导，可改为只备份正文。串行处理初始化与权限变更，避免重复注册脚本及恢复后的残留错误；补充附件权限错误的具体处理路径。
- **0.4.13**：修正设置页目录迁移提示，先复制完整归档、检查更新并按需补齐，不默认建议全量补采；补齐剩余优化验收清单、简短试用操作卡及空白记录表，准备固定提交的试用资料，尚未开始多人试用。
- **0.4.12**：首页按问题直达当前账号相关日志，补充按阶段处理建议和重置筛选；修复从另一个账号首页进入时仍沿用旧日志账号的问题。
- **0.4.11**：串联验证首次备份、升级与目录迁移；修复失败候选目录被恢复权限动作重放、新目录沿用旧检查冷却，以及旧目录附件数量残留。
- **0.4.10**：首页结果与问题入口前置，日常主操作简化，全量补采移入高级操作并确认账号；首次配置默认收起可选 GitHub。新增显式测试更新渠道、可重复安装包、校验及来源文件；正式稳定发布仍待完成。
- **0.4.9**：新增集中诊断入口、有限历史日志、失败聚合与步骤恢复标记、白名单脱敏导出、采集读取计数；重组使用与隐私说明。验证结果以 validation.md 为准。
- **0.4.8**：空闲展示复用账号核验，页面与操作事件重新确认；用户已确认空闲不再频繁核验。
- **0.4.7**：新增停止本轮，保留归档和交付记录；用户已确认显示停止状态。
- **0.4.6**：修复豆包增量基线遗漏渲染版本，未变化对话可跳过正文读取。
- **0.4.5**：按用户选择将单附件上限提高至 32 MiB。
- **0.4.4**：豆包附件签名地址刷新与 PowerShell 文本归档。
- **0.4.1–0.4.3**：豆包接入及旧格式图片、历史中断记录兼容。

更早实现细节见 [历史实现记录](technical-guide.md) 和 [旧版 0.2 指南](v0.2-guide.md)。
