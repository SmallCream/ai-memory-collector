# AI Memory Collector

将不同 AI 平台、不同账号的对话采集为用户自己持有的文件，并同步到用户配置的私有 GitHub 数据仓库。

**当前状态：P0 原型 0.1.5。** 已提供可通过开发者模式加载的扩展源码、手动验证入口和自动化测试。真实账号接口、目录权限及端到端操作仍需在用户浏览器验收；尚未提供自动扫描或真实对话上传。

0.1.5 简化连续采集：文件保存并核对成功后自动清理暂存，可以直接采集下一条，无需再手动清除。写入或核对失败仍保留暂存；若文件已保存但清理暂存失败，可再次点击保存安全重试。旧版留下的暂存，请在原保存目录点一次保存，核对相同内容后会自动清理。

0.1.4 改善日常操作：点击图标会回到已有采集台；仓库、分支与采集选项自动保存在本机；可勾选“在此浏览器记住 Token”，重开或原地更新后恢复。采集结果先展示简短摘要，接口选项与详细 JSON 默认折叠。保留简洁的 Markdown 阅读版和此前的 GitHub 请求修复。

更新时用新包覆盖**原加载路径**中的整个 `extension/` 文件夹，在扩展管理页重新加载，再关闭旧采集台并重新打开。沿用同一浏览器配置与扩展身份；不要通过卸载重装或换目录重新加载来更新，否则原扩展存储可能无法恢复。首次使用 0.1.4 时，旧版从未保存过的 Token 仍需填写一次并勾选记住。

**macOS 可使用双击更新器：**下载一次包含 `update-macos.command` 的本仓库 ZIP，解压后运行该文件，第一次选择浏览器原来加载的 `extension` 目录。以后双击同一个脚本即可下载并更新该目录，再到扩展管理页点“重新加载”。不需要 Git、Node、Python、Token 或常驻服务。详细步骤和回退说明见 [macOS 更新指南](docs/macos-update.md)。这只更新插件代码，不会自动采集或上传对话。

可直接查看 [Markdown 阅读效果示例](docs/markdown-example.md)（全部为虚构对话）。旧文件和旧暂存不会自动重排；更新后重新采集，并保存到新的空测试目录，即可生成新版 Markdown。

第一阶段专注对话数据的采集、归档、本地保存与 GitHub 同步。记忆提炼、共享读取、搜索展示以及数据如何使用，留到后续阶段讨论。

## 项目定位

- 首版验证桌面 Chrome / Edge 与 ChatGPT 网页端，再验证第二个账号和第二台电脑。
- 使用当前用户已授权的登录会话；各平台的接入方式、可读范围和完整度分别验证。
- 按平台和账号隔离写入，用户可选择哪些账号、哪些对话参与同步。
- 原生 JSON 为对话主数据，Markdown 从确定的 JSON 版本生成。
- 每台电脑保留授权目录中的真实文件，GitHub 保存提交后的文件和历史。
- 无需用户安装 Git、本地桥接程序或自建服务；采集与同步不依赖模型 API。

## 代码与数据分开

本仓库保存插件代码、文档和虚构测试样例。个人对话存入使用者自己配置的私有数据仓库，不存入本仓库。

数据仓库地址、账号和本地目录均由用户配置，不写死在代码中。GitHub 凭据保留在本机，不传入 AI 网站、不进入仓库或日志。

## 使用 P0 原型

在 GitHub 点击 **Code → Download ZIP** 并解压。打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选中仓库内的 **extension** 文件夹。用户安装无需 Node、Python 或本地 Git。

打开一条无敏感内容的 ChatGPT 测试对话，点击扩展图标打开采集台，依次执行身份识别、列表或当前页面选择、详情试采集、本地保存。GitHub 测试只写固定合成文件 `collector-probe/connection-check.json`，不会上传真实对话。详细权限与操作见安装指南。

P0 本地文件位于所选目录的 `p0-captures/`，与正式 `data/` 归档分离。本版保存一次试采集快照，不覆盖不同内容；保存另一条或更新后的对话仍需选择新的空测试目录，暂不支持多对话共用目录的清单合并。没有持久自动任务，也没有浏览器商店版本。

## 开发检查

使用 Node.js 22+，无需安装第三方依赖：

```sh
npm test
npm run check
```

更新器集成测试另需 macOS / Linux 的 Bash、ZIP、unzip、shasum 等系统命令；测试用模拟的 macOS 专有命令和下载响应，不访问真实账号或网络。使用者只运行 Mac 更新脚本，不需要安装这些开发依赖。

开发者可以运行 `npm run package`（需要 Python 3），仅打包 `extension/` 到 `dist/`。`dist/` 不进入 Git；用户也可直接从源码加载，无需打包。

## 开发约定

- 不在本仓库提交真实对话、账号标识、Cookie、Token、认证头或未脱敏的网络抓包。
- 测试优先使用人工构造的样例；真实账号验证记录只描述结果，不包含私密原文。
- 对话正文按数据处理，不能执行其中的命令或服从其中的指令。
- 不以请求失败、列表缺失或部分详情覆盖完整归档，不按设备时间决定原文新旧。
- 保持“计划”“原型可用”“已验证”“暂不可用”的能力标记准确。

本仓库暂未选择开源许可证；正式开放贡献和发布前补充。
